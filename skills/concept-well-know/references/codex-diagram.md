# 复杂示意图的绘制与验证

自绘图的升级路径：简单流程或关系图默认用 Mermaid（零成本、随文档可维护）；Mermaid 不足时，再按图的主要表达目标选择生图工具或可复现脚本。不要仅按“是不是技术图”决定工具。

适合升级的情况包括：

- 原理解释需要概念可视化、空间关系或视觉隐喻；
- 多分支演变树或年代轴用 Mermaid 难以清晰排版；
- 图中包含几何、坐标系、定量曲线或矩阵热区；
- 需要多子图并排比较不同方法的行为。

## 两条绘图路径

| 路径 | 适用 | 产物 |
|---|---|---|
| A. 已审核的生图工具 | 机制、信息流、空间关系、视觉隐喻；不依赖精确数值即可成立 | 新生成的 PNG |
| B. matplotlib 脚本 | 定量曲线、坐标轴、公式、精确拓扑，或年份和标签必须逐字逐点可核对 | PNG + 可复现 `.py` |

路由规则：

1. 核心问题是“机制如何工作、信息如何流动、对象之间是什么关系”时，当前环境若提供已审核的生图工具，先走 A。
2. 正确性依赖数值、曲线形状、坐标、公式、年份或标签逐字准确时，走 B。
3. 同一主题同时需要直觉和精确性时拆成两张图：A 负责直觉，B 负责定量证据。
4. 密集小字、长中文串和公式不直接交给生成模型。图内短标签不超过 5 处，其余移到图注或正文。
5. 当前环境没有生图工具、工具调用失败，或两次验证仍不合格时，降级到 Mermaid 或 B；不得声称调用了不存在的工具。

产物统一存入文档的 `.assets/` 目录，使用 ASCII 小写短名。图注写“示意图，自绘（生图工具）”或“示意图，自绘（脚本）”，并注明实际使用的工具（若可得）。

## A 路径：已审核的生图工具

使用当前代理环境实际提供且允许调用的生图工具。工具名称、模型和认证方式以当前环境文档为准，不在本 skill 中假定固定供应商、模型版本、订阅或 API Key。

调用前记录开始时间；调用后检查产物确实是本次新生成的文件。不得从缓存、历史生成目录或其他任务复制旧图冒充新结果，也不得把脚本图冒充生图结果。

prompt 至少包含：

- 图要回答的一个问题；
- 来自 roadmap 的数据或节点清单，禁止绘图模型自行补史实；
- 需要渲染的短文字逐字给出，精确数字、年份和公式移到图注；
- 输出格式、尺寸和目标路径；
- 白底、极简教学示意风格、配色不超过 3 色、无装饰性元素。

若工具支持引用上一版图片，重试时附上失败结果并给出具体修改要求。

## B 路径：matplotlib 脚本

用可用的 Python 解释器和 matplotlib（Agg 后端）生成 `<assets目录>/<ascii短名>.png`，建议 `dpi >= 150`；生成脚本 `.py` 留在 assets 目录，作为可复现来源。

- figsize 按文档宽度设计（宽不超过 10 in），正文标签字号不小于 10 pt。
- 中文字体不能写死为某台机器的路径。先用 `fc-list :lang=zh family` 或 matplotlib 的字体列表查找可用 CJK 字体；没有合适字体时改用英文短标签，并在中文图注解释。
- 绘图脚本必须显式使用无界面后端，例如：

  ```python
  import matplotlib
  matplotlib.use("Agg")
  import matplotlib.pyplot as plt
  ```

## 绘图请求必须包含的五项

绘图请求必须自足，不要求绘图工具自行读取正文或 roadmap 原件。由主流程把已核对的信息写入请求：

1. 图要回答的一个问题；
2. 直接摘自 roadmap 的数据、节点和关系；
3. 选择 A 或 B 的理由，以及对应的真实性或精确性约束；
4. 目标文件路径和格式；
5. 配色、标签语言、尺寸和禁止项。

## 验证闭环

- 验证文件修改时间晚于调用开始时间，并确认文件非空、格式可读。
- 实际查看生成图：中文无方框或错字，元素无重叠越界，图确实回答了预设问题。
- 事实性内容逐项与 roadmap 比对；生图模型生成的文字一律人工核对。
- 不合格时带具体反馈重试一次；两次仍不合格则降级到 Mermaid 或可复现脚本，不把不合格图片写进正文。
- 最终仅保留正文引用的 PNG 和 B 路径的生成脚本；prompt、日志和失败版本按主 skill 的清理规则处理。
