# 配图方法与验证

仅在图能帮助理解或用户要配图时读取。文件名保留来源名称；方法不绑定 Codex、固定模型或供应商，不要求工具可用就必须生图。

## 按信息选择工具

| 主要目的 | 可选方式 | 需要核对 |
|---|---|---|
| 流程、结构、调用链、分类 | Mermaid、HTML 组件或其他可编辑图形 | 节点、方向、条件和标签 |
| 数值曲线、坐标、公式、精确拓扑 | 已有绘图脚本或矢量工具 | 数据、单位、比例、计算与标签 |
| 直觉示意、空间关系、视觉类比 | 生图工具或手绘示意 | 是否忠实表达机制，有无虚构细节 |
| 原论文实验或架构证据 | 引用、提取或裁剪原图 | 版本、Figure 编号、完整性和来源 |

一种方式能表达清楚就用它，不为走流程重复画两张。生图中的精确数字、密集文字和公式容易失真，可移到正文或使用精确绘图；不能把重绘图当原始证据。

## 自绘与图源

绘图请求或脚本应说明图要回答的问题、已核对的节点或数据、关系和目标格式。风格与尺寸按交付载体和用户要求，不固定白底、三色或标签数量。不让生成工具自己补年份、方法关系、数据和结论。

使用环境实际提供的工具，不假定订阅、凭证、模型版本或字体路径。缺少工具时选择已有能力，只有确实影响结果才说明限制；不默认安装依赖或调用外部服务。

定量图适合保留数据与脚本以便复现。若用 matplotlib，可在没有交互窗口的环境使用 Agg 后端：

```python
import matplotlib
matplotlib.use("Agg")
import matplotlib.pyplot as plt
```

中文字体从现有字体中查找，没有时可用英文短标签加中文图注。尺寸、分辨率和字号按最终使用方式选择，查看实际图后决定，不以固定 inches / dpi 代替检查。

原图标论文名与 Figure 编号或原始链接；自绘标“机制示意”或“按某来源数据绘制”，注明必要的数据与工具。没有调用生图工具时不声称生成模型作图，也不把历史图冒充本次新生成的产物。

## 验证与文件

实际打开图检查可读性、文字、边界、重叠和内容；事实性节点、数值、曲线与来源对照。错误时按具体问题修正，不固定重试次数或降级顺序。

图片放用户指定或项目适合的位置，相对路径从最终文档计算。保存成品所需图片、数据与复现脚本；只清理本次无用中间产物，不扫描共享目录删除未被当前文档引用的其他图片。
