# paper-well-know：单篇论文阅读参考

> 从本仓库 PR #2 的论文精读 skill 改写。这里只保存阅读方法，唯一执行入口是根目录 [SKILL.md](../../SKILL.md)。按用户的问题选择深度，不默认生成固定报告、图表或推导。来源见 [SOURCES.md](../../SOURCES.md)。

用于理解单篇论文的问题、方法、证据和适用边界。原参考偏重计算机论文；理论、实证、综述与其他学科按材料特点组织，不补造实验或算法来套模板。

## 按问题决定读法

| 请求 | 读取与交付 |
|---|---|
| 解释一句话 / 一个公式 / 一张图 | 读对应内容及必要上下文，直接回答，不自动通读全文或写报告 |
| 论文讲什么 / 快速概览 | 读取支持概览的章节，交代依据；不能只读摘要却声称完整精读 |
| 为什么这样设计 / 实验支持什么 | 读相关方法、对照和讨论，围绕指定问题说明 |
| 全文精读 / 系统分析 | 全文精读覆盖正文与附录；系统分析围绕用户范围读取并核对相关图表，记录重要出处；必要时使用下方报告模板 |
| 值不值得读 / 贡献与不足 | 给有依据的判断，分清作者声明、原文证据与自己的评价，不回避评价 |
| 保存阅读笔记 | 按指定路径或项目布局写文档；聊天请求不默认落盘 |

多篇对比可把本参考作为单篇阅读方法，与根入口的综述写法组合；不自动调用另一个研究 skill。语言与简繁字形按用户选择。

## 来源与证据

使用用户给的 PDF、HTML 或版本。arXiv 可先读官方 HTML，必要时读 PDF 或 ar5iv；混用时核对版本、公式和表格编号。仅有标题时查找原论文，匹配有歧义才询问。无法取得全文时说明实际读到的范围，不凭模型记忆填论文细节。

PDF 可用已有 `pdfinfo`、`pdftotext -layout` 读取，复杂公式与表格回到页面查看。只有需要图片时才用 `pdfimages` 或 `pdftoppm`；工具不可用时说明受影响的部分，不自动安装。

长篇系统分析可建立工作笔记，帮助跨批次保持来源一致，不要求每次写成独立文件：

| 证据项 | 记录示例 |
|---|---|
| 身份与范围 | 标题、作者、版本、链接或本地来源、已读章节 |
| 贡献声明 | 作者在 Introduction / Conclusion 的声明位置 |
| 方法 | 关键 Figure / Algorithm / Equation 编号及作用 |
| 结果 | Table / Figure 编号、指标定义、对比设置 |
| 局限 | 原文 limitation、failure case，以及尚未覆盖的问题 |

重要数字、论断和解释应能回到具体出处，如“§3.2，Eq.5”或“Table 2”。博客、项目 README 和新闻稿可帮助理解，但单独标出来源，不能把它们当论文原文。

## 讲清方法与证据

- 先说明论文解决的问题与已有约束，再讲关键设计怎样回应它。不要用“任务重要”替代具体动机。
- 流程型方法可按输入、处理、中间表示、输出讲解；关系复杂且图有帮助时再画流程图。理论或非算法论文使用适合的概念、论证或研究设计结构。
- 公式先说明符号与作用，只有请求涉及推导或理解离不开公式时才展开。复杂符号可用统一符号表，短解释可在正文直接定义。
- 每步变换注明原文公式、数学依据或“补充推导”。不强迫独立模块组成一条实际不存在的推导链。
- 分析结果时说明指标、比较条件与结论的关系。不同数据、backbone、训练预算、分辨率或额外数据不能直接据数字判定谁更优。
- 区分“作者声称”“结果显示”和“据此我的判断”。可以指出证据不足、原文矛盾或值得肯定之处，判断附理由；没有说明的细节不补成事实。

原文解释与自己的补充可用自然语言区分，例如“原文在 Eq.3 给出……”“为说明这一步，下面补一个例子……”。不用固定 emoji、颜色或引用块标记。

## 可选报告、图片与交付

用户需要系统笔记时，按 [report-template.md](references/report-template.md) 选择章节，标题与顺序可随问题变化。没有数学、实验或公开图片时省略不适用章节；只有该缺失影响判断时才说明，不为填满模板编内容。

取图优先选择支持讲解的原图；重绘时标明“示意重绘”，不能当作原始证据。PDF 裁图的工具和坐标细节见 [翻译参考的图表处理](../paper-translate/source.md#图表处理)，只在需要取图时读取。

保存文件遵循根入口的路径规则，不要求预先存在某个私人目录。图片名在共享目录中避免重名，从最终文档位置验证链接。保留源论文、成品与引用图片，只清理本次无用的临时产物。

聊天任务直接给答案或分析；文件任务给成品链接与必要的范围、来源和限制。只有用户要求审计过程或验证报告时才列核对统计，不例行汇报每张图、每个公式的数量。
