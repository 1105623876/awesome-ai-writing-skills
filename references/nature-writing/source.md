# Nature 章节写作参考

选自 [Yuan1z0825/nature-skills](https://github.com/Yuan1z0825/nature-skills) 的 `nature-shared/core/`，在本项目中作为普通参考使用。固定版本和改写范围见 [SOURCES.md](../../SOURCES.md)，原许可见 [LICENSE](LICENSE)。本目录没有独立 skill 入口。

这五份文件保留章节方法、判断依据、例子和例外，适合解决摘要散乱、引言缺乏问题、Results 重复、Discussion 只重述结果等具体问题。它们来自上游作者的语料归纳，不是 Nature 官方写作标准，也不代表采用这些写法就适合该刊。

| 当前问题 | 参考 |
|---|---|
| 摘要怎样交代贡献、依据与范围 | [nature-abstract.md](references/nature-abstract.md) |
| 引言怎样把文献接到具体问题 | [nature-introduction.md](references/nature-introduction.md) |
| Results 怎样组织证据，Discussion 怎样综合结果 | [nature-results-discussion.md](references/nature-results-discussion.md) |
| Discussion 怎样解释、比较文献、表达不确定性 | [discussion-argument-language.md](references/discussion-argument-language.md) |
| 正文怎样压缩、保留必要证据、安排补充材料 | [main-text-discipline.md](references/main-text-discipline.md) |

只读当前问题对应的部分。发现型论文可以借用问题与证据逐步展开的写法；方法、理论、资源论文及综述按自身贡献组织。方法论文投计算机会议时，引言与相关工作改读 [CCF 章节参考](../ccf-writing-skills/references/section-modules.md)。局部润色保留原有结构，已经清楚的文字可以不改。结构表和诊断问题用于难以理清的段落或用户要求的审阅，不是动笔前必须填写的材料，也不默认生成过程记录。

沿用根入口的改稿范围、事实与论断规则。润色时发现证据不足，指出具体位置并建议合适措辞；只有获得实质修订授权时才改动论断。涉及新实验的建议与已完成结果分开，移动正文或补充材料也须在当前授权范围内。
