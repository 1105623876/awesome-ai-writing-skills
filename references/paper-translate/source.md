# paper-translate：论文翻译参考

> 从本仓库 PR #2 的论文翻译 skill 改写。这里只保存方法与例子，唯一执行入口是根目录 [SKILL.md](../../SKILL.md)。按当前请求选择范围、译法和交付形式，不继承原作者的目录布局或学习习惯。来源与改写记录见 [SOURCES.md](../../SOURCES.md)。

适用于论文与技术材料的翻译，包括粘贴片段、本地 PDF / HTML / Markdown、arXiv 和其他网页。原参考偏重 CV、CS、LLM；方法可用于其他学科，术语以相应领域为准。

## 选择范围与译法

先从请求确定目标语言、范围和形式，信息足够就翻译。只有来源或范围的歧义会实质改变结果时才询问。

| 请求 | 处理 |
|---|---|
| 粘贴文本 | 翻译这段，不另找全文替换 |
| 指定章节 / 页码 | 核对标题和起止；跨页句子补全上下文，不擅自扩展整章 |
| 全文 | 覆盖标题、摘要、正文、图表说明、脚注、附录及其他文字；参考文献条目的题名与出版信息通常保留原文。交代实际范围，不能默默排除附录 |
| 只要译文 / 仅翻译 | 直接给译文，不自动加原文、解释、术语表或生词表 |
| 英中对照 | 按自然段交替；用户要求逐句时改为句对照 |
| 严格逐句对照 | 一个原句对应一个译句，保留句序；不能概括、合句或拆成多句 |
| 自然流畅的翻译 | 可按目标语言拆长句或调整句内语序，保留全部语义、条件和论断强度 |
| 翻译并解释术语 | 译文之外另附说明，分清原文内容和译者解释 |

未指定形式时默认给忠实、自然的译文。语言、简繁字形、引用和格式服从当前用户，不默认所有读者都是英语学习者。

## 取得原文

- 本地 PDF：先查页数，用 `pdftotext -layout` 分页读取；公式、上下标、跨栏和复杂表格对照页面图像。
- 本地 HTML / Markdown：直接读取，保留图表、公式和引用编号。
- arXiv：可先读 `https://arxiv.org/html/{id}`，不可用时读取官方 PDF，或用 ar5iv 辅助理解。记录版本，不能把镜像或另一版本的内容无声混入用户材料。
- 其他 URL：读取正文并记录来源，页面不完整时说明缺口。
- 仅有标题：查找原论文，核对标题、作者和年份；匹配唯一且可信时直接使用并注明来源，有同名或不同版本歧义时才让用户选择。

PDF 分页读取的命令示例：

```sh
pdfinfo paper.pdf
pdftotext -f 1 -l 8 -layout paper.pdf -
```

PDF 提取的硬换行不是自然段。根据页面、空行、缩进和语意复原段落；`e.g.`、`i.e.`、`et al.`、`Fig. 3`、`Eq. (2)` 中的句点不是分句依据。扫描件无法可靠识别的地方标记原文不清，不猜内容。

## 忠实与术语一致

- 保留事实、数字、单位、否定、条件、引文标记与 may / should / must 的强度；翻译不变成摘要或评论。
- 行内公式与变量原样嵌入；独立公式保留原式和编号。发现疑似原文错误时单独说明，不能悄悄改公式。
- 术语采用当前学科通行译法，同一概念全文同名；无可靠译法时保留原词。方法、模型、数据集和指标名不强行意译。
- 首次出现的陌生术语可写成“中文译名（English term）”，以读者需要为准，不要求全部加粗或编号。
- 允许调整被动句与长定语，使译文自然。用户要求严格句对照时在对应句内部调整，不跨句重组。

## 对照示例

段落对照把一个自然段放进一个引用块，中文另起段落：

```markdown
> The model shares parameters across layers. This reduces memory use.

模型在各层之间共享参数。这降低了内存占用。
```

逐句对照用于需要对照句法或精读的小范围材料：

```markdown
> The model shares parameters across layers.

模型在各层之间共享参数。

> This reduces memory use.

这降低了内存占用。
```

引用块与译文之间留空行，避免 Markdown 把译文也纳入引用。标题、公式、图表 caption 可以单列，不并入相邻正文。

## 长文与可选学习注释

长文在段落或小节边界分批，不能留下只有原文、没有译文的半个对照单元。接续前核对已译范围、术语和编号，避免重复、遗漏或译名漂移。已授权保存全文时自主分批完成文件，不要求用户逐批批准；聊天受长度限制时标明进度和下一处起点，不声称已经译完。

用户需要术语学习时，可按首次出现顺序列出术语，解释“是什么、在这篇材料里做什么”。使用正文上标时，表中编号与上标对应，并与论文 `[12]` 引文区分。用户需要词汇学习时，按其水平选择普通词汇，给出本文义项；IPA 只在用户需要且能可靠核实时提供，不默认四六级标准。

```markdown
## 术语解释
1. **注意力机制（attention mechanism）**：根据当前查询，为不同输入分配权重。

## 词汇说明
- `perturbation`：扰动；本文指对输入施加的小幅变化。
```

术语与普通词汇不重复收录。聊天分批只附当批新增条目、保持全篇编号；保存文档时可在末尾集中列一次。未请求学习注释时不执行这些步骤。

## 图表处理

仅在需要图文交付时读取本节。caption 属于译出范围时翻译并保留编号。聊天可引用原图所在页；文件需要图文阅读时才提取或裁图，不为纯译文任务生成配图。

表格可重排为 Markdown，保留方法名、指标、单位、上下标、± 与数字精度。文本提取与 `pdfplumber.extract_tables()` 都可能错列，重要数据回到页面核对。过宽时分表并标明续表，不删列；格式不能可靠重排时保留原表图和文字说明，不猜单元格。

取图可选官方 HTML 原图、`pdfimages` 提取内嵌位图或 `pdftoppm` 页面裁剪。矢量图常不能用 `pdfimages` 完整抽取，直接渲染目标区域通常更可靠。

### PDF 裁图与坐标

先低分辨率渲染目标页，查看图的位置，再按高分辨率裁剪。下面的数值仅为命令示例，使用时根据实际页面重算：

```sh
pdftoppm -png -r 100 -f 3 -l 3 -singlefile paper.pdf page3
pdftoppm -png -r 300 -f 3 -l 3 -singlefile \
  -x 250 -y 180 -W 1600 -H 900 paper.pdf figure2
```

- 像素 = point × DPI / 72；页面尺寸查 `pdfinfo`，不默认 Letter 或 A4。
- `-x -y -W -H` 是当前 DPI 的像素。从 100 DPI 的定位框转为 300 DPI 时，四个值都乘 3，不把低分辨率坐标直接复用。
- `-singlefile` 可避免自动页码后缀导致文件名判断错误。
- 用 `pdfplumber` 辅助定位时，位图看 `page.images`，矢量对象可看 `curves / rects / lines`；不能假设存在 `page.figures`。
- `top / bottom` 自顶向下，适合转换为裁剪框；`y0 / y1` 是自底向上的 PDF 坐标，不能直接当作 `-y`。point 换像素仍乘 DPI / 72。
- 页面旋转、CropBox 或缩放可能影响坐标，实际查看成品，确认没有缺角、正文混入或裁掉图注。复杂拼接可用已有图像工具，不增加无关依赖。

## 保存翻译时

文件与清理遵循根入口的“材料、载体与文件”。译稿保留来源、版本和译出范围；图名避免与其他论文重名，相对路径从最终译稿位置计算。这里不约定私人目录布局。
